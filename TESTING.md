## 🎯 Рекомендации

**Перед запуском бота:**
1. Запустите `python test_bot.py` - проверка всех импортов
2. Убедитесь, что Ollama запущен
3. Проверьте доступ к БД

**Для мониторинга:**
1. Используйте `python monitor_logs.py` для запуска с логами
2. Следите за ошибками в реальном времени
3. Ctrl+C для остановки и просмотра статистики

**Для разработки:**
1. Используйте `python quick_test.py` после изменений
2. Проверяйте основные функции перед коммитом
3. Дорабатывайте pytest тесты по мере разработки

## 📦 Зависимости для тестов

Уже установлены:
- pytest >= 8.0.0
- pytest-asyncio >= 0.23.0
- pytest-cov >= 4.1.0
- aiosqlite >= 0.19.0
