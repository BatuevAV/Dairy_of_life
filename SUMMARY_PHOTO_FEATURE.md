## 🚀 Запуск

### Шаг 1: Получить Gemini API ключ

1. Откройте: https://makersuite.google.com/app/apikey
2. Войдите через Google
3. Нажмите "Create API Key"
4. Скопируйте ключ

**Бесплатный лимит:**
- 15 запросов/минуту
- 1500 запросов/день

### Шаг 2: Добавить в .env

```bash
nano .env
```

Добавьте строку:
```
GEMINI_API_KEY=ваш_ключ_здесь
```

### Шаг 3: Запустить бота

```bash
source venv/bin/activate
python -m bot.main
```

### Шаг 4: Протестировать

Отправьте боту фото еды! 📸

## 🔧 Технические детали

### Prompt Engineering
```python
def _build_prompt(self, additional_context: Optional[str] = None) -> str:
    base_prompt = """
    Ты - эксперт по питанию. Проанализируй фото еды и дай оценку.
    
    ВАЖНО: Отвечай ТОЛЬКО в JSON формате:
    {
      "detected_items": ["список блюд"],
      "description": "подробное описание",
      "calories": число,
      "protein": граммы,
      "fat": граммы,
      "carbs": граммы,
      "confidence": 0.0-1.0,
      "confidence_level": "low/medium/high",
      "clarification_questions": [...],
      "assumptions": ["что предположил"]
    }
    """
```

### Обработка фото
1. `message.photo[-1]` - самое большое разрешение
2. `bot.get_file()` → `bot.download_file()` → bytes
3. `base64.encode()` для Gemini API
4. POST запрос с inline_data
5. Парсинг JSON ответа

### FSM States
- `waiting_for_clarification` - ожидание ответов на вопросы
- `waiting_for_confirmation` - ожидание подтверждения

### Сохранение
```python
day_entry.kcal_eaten += estimate.calories
day_entry.photo_analyzed = True
day_entry.food_ai_estimated = True
day_entry.food_ai_confidence = estimate.confidence
day_entry.photo_description = estimate.description
user.ai_requests_today += 1
```
