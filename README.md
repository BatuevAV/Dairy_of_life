# Telegram Bot: Дневник питания и расхода калорий

Telegram-бот для отслеживания питания, физической активности и расчёта баланса калорий.

## 🎯 Возможности

- ✍️ **Два режима ввода**: свободный текст или пошаговый диалог
- � **Распознавание еды по фото**: AI анализ с уточняющими вопросами (Google Gemini Vision)
- 🤖 **AI оценка калорий**: локальный Ollama для текста, Gemini для фото
- 📊 **Автоматический расчёт**: BMR, расход калорий, баланс
- 👥 **Мульти-пользователь**: white-list система с ролями (владелец/разрешённые)
- 📈 **Отчёты**: сводка за день, неделю
- 📥 **Экспорт в Excel**: полный дневник с графиками
- ⚙️ **Настройки**: персонализация расчётов под свои параметры
- 🔒 **Приватность**: фото не сохраняются по умолчанию

## 📋 Что отслеживает бот

- **Питание**: калории, БЖУ (белки/жиры/углеводы)
- **Активность**: шаги, тренировки (зал, плавание, бег, велосипед)
- **Параметры тела**: вес, обхват талии
- **Сон**: продолжительность
- **Баланс калорий**: съедено vs израсходовано

## 🛠 Технологии

- Python 3.9+
- aiogram 3.13 (Telegram Bot Framework)
- PostgreSQL (база данных)
- SQLAlchemy 2.0 (async ORM)
- OpenPyXL & Pandas (экспорт Excel)
- Ollama + llama3.2 (локальный AI для текста)
- Google Gemini Vision API (AI для фото, бесплатный tier)

## 📝 Команды бота

### Основные команды
- `/start` - Начать работу с ботом
- `/mode` - Выбрать режим ввода (свободный/пошаговый)
- `/add` - Добавить запись (пошаговый режим)
- Просто отправьте **фото еды** - бот автоматически распознает! 📸

### Отчёты
- `/today` - Сводка за сегодня
- `/yesterday` - Сводка за вчера
- `/week` - Статистика за 7 дней
- `/export` - Экспорт данных в Excel

### Настройки
- `/settings` - Настройки профиля
- `/help` - Справка

### Админ команды (только владелец)
- `/allow <user_id>` - Добавить пользователя в white-list
- `/disallow <user_id>` - Убрать пользователя
- `/users` - Список пользователей и статистика AI

## 💡 Примеры использования

### 📸 Фото (самый простой способ!)

1. Просто отправьте фото еды боту
2. Бот распознает что на фото и посчитает калории
3. Ответьте на 1-3 уточняющих вопроса
4. Подтвердите запись

```
Вы: [фото пасты]
Бот: 📸 Я вижу: паста с курицей, соус сливочный
     Оценка: ~820 ккал, БЖУ: 40/30/85г
     
     Уточните: Соус какой?
     [кнопки: сливочный | томатный | без соуса]
     
Вы: [нажимаете "сливочный"]
Бот: ✅ Записано! +820 ккал
```

📖 Подробнее: [PHOTO_READY.md](PHOTO_READY.md)

## 🔧 Настройка профиля

Бот использует формулу Mifflin-St Jeor для расчёта BMR:
```
BMR = 10 × вес(кг) + 6.25 × рост(см) − 5 × возраст + 5 (для мужчин)
```

Коэффициенты по умолчанию:
- Шаги: 0.026 ккал/шаг
- Зал: 375 ккал/час
- Плавание: 500 ккал/час
- Бег: 600 ккал/час
- Велосипед: 450 ккал/час

Все коэффициенты можно настроить через `/settings`.

## 📊 Расчёт баланса

```
Расход = BMR + Калории_от_шагов + Калории_от_тренировки
Баланс = Съедено − Расход
```

- **Баланс < -200**: дефицит (зелёный)
- **Баланс -200...+200**: норма (жёлтый)
- **Баланс > +200**: профицит (красный)
